# 二、产品概述

## 2.1 核心目标

开发一款适配 macOS 系统的手势增强工具，以“直观、高效、自定义”为核心，解决 macOS 原生手势功能有限、键盘快捷键晦涩难记的痛点，让用户通过简单的鼠标/触控板手势，快速完成系统操作、应用控制等场景，提升桌面操作效率，同时支持高度自定义配置，适配不同用户的使用习惯，打造比 WGestures2 更贴合 macOS 原生体验的手势工具。（SMART 目标：上线后3个月内，核心用户日均使用手势次数≥50次，用户满意度≥85%）

## 2.2 背景与意义

macOS 系统虽自带触控板手势功能，但存在功能局限，无法满足专业用户的高效操作需求；而键盘快捷键需大量记忆，且难以直观对应操作命令，学习成本较高。WGestures2 作为 Windows 平台成熟的手势工具，其“手势触发+自定义动作”的核心逻辑广受好评，但缺乏对 macOS 系统的深度适配。本产品将借鉴 WGestures2 的优势，结合 macOS 系统特性（如原生交互逻辑、应用生态、系统权限），填补 macOS 平台高质量手势增强工具的缺口，帮助用户摆脱繁琐操作，实现“一划即达”的高效桌面体验。同时，当前 macOS 手势工具（如 jitouch、BetterTouchTool）存在功能冗余或适配不足的问题，本产品将以“轻量化+高适配”为特色，打造差异化优势。

## 2.3 范围界定

### 2.3.1 本次开发范围（做什么）

- 核心功能：鼠标手势（右键/中键触发）、触控板手势（原生手势扩展）、手势自定义配置、场景化手势（全局/特定应用）；

- 基础功能：手势轨迹显示、手势触发反馈、常用手势预设、手势冲突检测；

- 扩展功能：修饰键组合手势、脚本扩展（支持 AppleScript）、屏幕触发角、手势备份/导入导出；

- 适配范围：macOS 12.0+ 系统，支持常见鼠标（有线/无线）、macOS 原生触控板。

### 2.3.2 本次不开发范围（不做什么）

- 暂不支持触摸屏手势（针对外接触摸屏设备，后续版本可迭代）；

- 暂不开发移动端同步功能（如手机控制电脑手势）；

- 暂不支持复杂的多手势联动（如连续触发两个手势执行组合动作）；

- 暂不集成第三方应用插件商店（仅支持本地脚本导入）。

# 三、用户与场景分析

## 3.1 目标用户

### 3.1.1 核心用户

macOS 专业用户（程序员、设计师、文案编辑、办公人士）：日常高频使用电脑，追求操作效率，对桌面操作的便捷性有较高需求，熟悉电脑基础操作，愿意花时间配置自定义手势。

### 3.1.2 次要用户

macOS 新手用户：不熟悉键盘快捷键，希望通过简单直观的手势操作电脑，需要预设好的常用手势，降低学习成本；Windows 转 macOS 用户：习惯 WGestures2 等手势工具，需要一款功能类似、适配 macOS 的替代工具。

## 3.2 核心用户场景（用户故事格式）

- 作为【程序员】，我希望按住鼠标右键划动特定轨迹，快速打开终端、切换窗口，以便减少重复操作，提升编码效率；

- 作为【设计师】，我希望通过触控板手势快速调整屏幕亮度、切换桌面，以便在设计过程中无需切换到系统设置，专注创作；

- 作为【办公人士】，我希望自定义手势实现“复制/粘贴/撤销”操作，以便替代键盘快捷键，减少记忆负担，提升办公效率；

- 作为【Windows 转 macOS 用户】，我希望找到一款类似 WGestures2 的手势工具，保留熟悉的手势操作逻辑，快速适应 macOS 系统；

- 作为【多应用使用者】，我希望针对浏览器、办公软件设置单独的手势，以便在不同应用中实现差异化操作，避免手势冲突。

# 四、功能详细需求（AI 友好，可直接对接开发）

说明：所有功能描述均明确操作流程、触发条件、规则逻辑，无模糊表述，研发可直接基于此进行编码，测试可直接提取验收点。

## 4.1 核心功能模块：手势操作（鼠标+触控板）

### 4.1.1 鼠标手势

- 功能名称：鼠标手势触发

- 触发条件：用户按住指定鼠标按键（默认右键/中键，可自定义），在屏幕上划动预设轨迹，松开按键后触发对应动作；

- 操作步骤：
        

    1. 用户在应用配置界面，选择“鼠标手势”模块，设置触发按键（右键/中键/左键+修饰键，左键默认不单独作为触发键，避免与日常操作冲突）；

    2. 选择“添加手势”，划动目标轨迹（如上下左右滑动、圆形、三角形、字母轨迹等）；

    3. 为该轨迹绑定对应动作（如系统操作、应用操作、脚本等）；

    4. 保存配置后，在桌面/应用中按住触发按键，划动对应轨迹，松开按键即可执行绑定动作。

- 规则说明：
        

    - 轨迹识别精度：支持调节（低/中/高），高精度模式下识别更精准，但对划动轨迹要求更高；低精度模式下容错率高，适合新手；

    - 轨迹显示：划动手势时，屏幕实时显示轨迹线条（颜色、粗细可自定义），便于用户确认轨迹是否正确，执行动作后轨迹自动消失；

    - 预设手势：内置10+常用手势（如上下滑动=滚动页面、左右滑动=浏览器前进/后退、圆形=打开启动台、对角线滑动=关闭当前窗口等），用户可直接启用/禁用/修改；

    - 冲突处理：若两个手势轨迹相似，系统自动提示“可能存在冲突”，建议用户修改其中一个轨迹，或设置不同的触发按键。

- 异常场景处理：
        

    - 轨迹识别失败：划动轨迹不清晰或与预设轨迹偏差过大时，屏幕显示“识别失败”提示（提示时长可自定义），不执行任何动作；

    - 触发按键被占用：若触发按键被其他应用占用，系统提示“触发按键冲突，请更换按键”；

    - 手势执行失败：绑定的动作不存在（如绑定的应用未安装），系统提示“动作执行失败，请检查绑定配置”。

### 4.1.2 触控板手势（原生扩展）

- 功能名称：触控板手势扩展

- 触发条件：用户在 macOS 原生触控板上，执行预设的多手指手势（如三指、四指），触发对应动作（补充原生手势未覆盖的功能）；

- 操作步骤：
        

    1. 用户在应用配置界面，选择“触控板手势”模块，查看原生手势列表（避免重复配置）；

    2. 选择“添加扩展手势”，设置手指数量（3指/4指/5指）、手势动作（滑动/点击/捏合/张开）；

    3. 为该手势绑定对应动作（如三指下滑=显示桌面、四指点击=打开通知中心等）；

    4. 保存配置后，在触控板上执行对应手势，即可触发绑定动作。

- 规则说明：
        

    - 不覆盖原生手势：系统自动检测 macOS 原生触控板手势，用户无法配置与原生手势重复的手势（如双指捏合=缩放，禁止重复配置）；

    - 手势灵敏度：可调节触控板手势的触发灵敏度（低/中/高），适配不同用户的操作习惯；

    - 预设扩展手势：内置5+常用扩展手势（如三指左右滑动=切换应用、四指捏合=关闭所有窗口等），用户可直接启用/修改。

- 异常场景处理：
        

    - 原生手势冲突：用户尝试配置与原生手势重复的手势时，系统提示“该手势为 macOS 原生手势，无法重复配置”；

    - 手势未识别：触控板操作不规范（如手指数量不足、动作不连贯），系统不触发动作，无额外提示（避免干扰用户）。

## 4.2 核心功能模块：手势自定义配置

### 4.2.1 手势动作绑定

- 功能名称：手势-动作绑定

- 触发条件：用户在手势配置界面，选择已创建的手势，点击“绑定动作”；

- 支持的动作类型（覆盖 WGestures2 核心动作，适配 macOS）：
       

    - 系统操作：打开/关闭桌面、切换桌面、调整屏幕亮度/音量、打开启动台、打开通知中心、锁定屏幕、重启/关机等；

    - 应用操作：打开指定应用、关闭当前应用、切换当前应用、最小化/最大化当前窗口、全屏/退出全屏等；

    - 键盘快捷键映射：将手势绑定为任意键盘快捷键（如 Cmd+C=复制、Cmd+V=粘贴），支持自定义快捷键组合；

    - 脚本扩展：支持导入 AppleScript 脚本，绑定手势后，触发手势即可执行脚本（如自动拨号、切换 Apple ID 等）；

    - 网页操作：打开指定网址、刷新当前网页、关闭当前网页标签等（仅针对浏览器场景）；

    - 自定义菜单：绑定自定义菜单（如常用文件/文件夹路径），触发手势后显示菜单，用户点击可执行对应操作。

- 操作步骤：

    1. 选择已创建的手势，点击“绑定动作”按钮；

    2. 选择动作类型（如“系统操作”），再选择具体动作（如“调整屏幕亮度”）；

    3. （可选）设置动作参数（如调整亮度的幅度、打开应用的路径）；

    4. 点击“保存”，完成绑定，可点击“测试”按钮，验证手势是否能正常触发动作。

### 4.2.2 场景化手势配置

- 功能名称：全局/特定应用手势配置

- 触发条件：用户在手势配置界面，选择“场景设置”，可设置手势的生效范围；

- 生效范围类型：
        

    - 全局生效：手势在所有桌面、所有应用中均可触发（默认场景）；

    - 特定应用生效：仅在用户指定的应用中触发（如仅在 Chrome 浏览器中生效“左右滑动=前进/后退”手势）；

    - 排除应用：全局手势在指定应用中不生效（如在 Photoshop 中，不触发任何手势，避免干扰设计操作）。

- 操作步骤：
        

    1. 选择已创建的手势，点击“场景设置”；

    2. 选择生效范围（全局/特定应用/排除应用）；

    3. 若选择“特定应用/排除应用”，点击“添加应用”，从已安装应用列表中选择目标应用（支持搜索）；

    4. 保存配置，即可实现场景化手势生效。

- 规则说明：特定应用手势优先级高于全局手势，即当用户在特定应用中时，仅执行该应用的专属手势，全局手势暂不生效。

### 4.2.3 手势备份与导入导出

- 功能名称：手势配置备份/导入/导出

- 触发条件：用户在配置界面，点击“备份/导入/导出”按钮；

- 操作步骤：
        

    1. 备份：点击“备份配置”，系统自动将当前所有手势配置（包括手势轨迹、动作绑定、场景设置）保存为 .gest 格式文件，用户可选择保存路径；

    2. 导出：点击“导出配置”，选择目标手势配置（可选择单个手势或全部手势），保存为 .gest 格式文件；

    3. 导入：点击“导入配置”，选择本地 .gest 格式文件，系统自动解析并添加对应手势配置，若存在同名手势，提示用户“覆盖/保留”。

- 规则说明：备份文件支持跨设备导入（如在另一台 macOS 设备上导入配置，无需重新设置）。

## 4.3 基础功能模块：手势辅助功能

### 4.3.1 手势轨迹显示与反馈

- 功能名称：手势轨迹显示、触发反馈

- 触发条件：用户执行手势操作时，自动触发轨迹显示；手势识别成功/失败时，触发对应反馈；

- 具体需求：
        

    - 轨迹显示：划动手势时，屏幕实时显示轨迹（颜色、粗细、透明度可自定义），轨迹跟随鼠标/触控板移动，动作执行后1秒内自动消失；

    - 触发反馈：
               

        - 识别成功：屏幕显示短暂提示（如“手势执行成功”，提示时长可自定义），同时播放轻微提示音（可关闭）；

        - 识别失败：屏幕显示“识别失败”提示，无提示音（避免干扰用户）；

        - 动作执行失败：屏幕显示“动作执行失败，请检查配置”提示，播放轻微警告音（可关闭）。

### 4.3.2 手势冲突检测

- 功能名称：手势冲突检测

- 触发条件：用户创建/修改手势时，系统自动检测是否存在冲突；

- 冲突类型：
       

    - 轨迹冲突：两个手势的轨迹相似（相似度≥80%），且触发按键、生效场景相同；

    - 触发按键冲突：两个手势的触发按键相同，且生效场景、轨迹相同；

    - 系统冲突：手势绑定的动作与 macOS 系统快捷键、原生手势冲突。

- 处理逻辑：检测到冲突时，系统立即提示冲突类型，并给出解决方案（如“轨迹相似，请修改其中一个手势的轨迹”“触发按键冲突，请更换触发按键”），用户未解决冲突前，无法保存手势配置。

### 4.3.3 应用启停与后台运行

- 功能名称：应用启停、后台运行设置

- 触发条件：用户点击应用主界面“启动/停止”按钮，或在系统偏好设置中配置后台运行；

- 具体需求：
        

    - 启动：点击“启动”按钮后，应用进入后台运行，菜单栏显示应用图标，手势功能生效；

    - 停止：点击“停止”按钮后，应用停止后台运行，菜单栏图标消失，手势功能失效；

    - 后台运行设置：支持设置“开机自启”（默认关闭），开启后，macOS 启动时，应用自动进入后台运行，手势功能自动生效；

    - 后台占用：应用后台运行时，CPU 占用率≤5%，内存占用≤100MB（避免影响系统流畅度）。

## 4.4 扩展功能模块

### 4.4.1 修饰键组合手势

- 功能名称：修饰键+手势组合触发

- 触发条件：用户按住指定修饰键（Cmd、Option、Control、Shift），同时执行手势操作，触发对应动作；

- 具体需求：
        

    - 支持单个/多个修饰键组合（如 Cmd+Option+手势）；

    - 用户可在手势配置界面，为每个手势设置专属修饰键组合，实现“同一轨迹+不同修饰键=不同动作”（如右键划动右→左：无修饰键=浏览器后退，Cmd+右键划动右→左=关闭当前标签）；

    - 修饰键冲突检测：系统自动检测修饰键组合是否与系统快捷键、其他手势冲突，存在冲突时提示用户修改。

### 4.4.2 屏幕触发角

- 功能名称：屏幕角落触发手势/动作

- 触发条件：用户将鼠标移动到屏幕四个角落（可设置触发区域大小），停留指定时间（可自定义），触发对应手势或动作；

- 具体需求：
        

    - 支持为四个屏幕角落分别绑定动作（如左上角=打开启动台、右上角=锁定屏幕、左下角=显示桌面、右下角=打开通知中心）；

    - 可设置触发区域大小（小/中/大），避免误触发；

    - 可设置停留时间（0.1-1秒），默认0.3秒；

    - 与 macOS 原生触发角兼容：用户可选择“覆盖原生触发角”或“保留原生触发角”，保留时，本应用触发角不生效。

### 4.4.3 脚本扩展（高级功能）

- 功能名称：AppleScript 脚本导入与执行

- 触发条件：用户导入 AppleScript 脚本，绑定到手势后，执行手势触发脚本；

- 具体需求：

    - 支持导入 .scpt 格式的 AppleScript 脚本，可手动输入脚本内容，也可选择本地脚本文件；

    - 脚本预览：导入脚本后，可点击“预览”按钮，查看脚本内容，验证脚本是否可正常执行；

    - 脚本错误提示：若脚本存在语法错误，系统提示“脚本错误，请检查脚本内容”，并标注错误位置；
